# Snake Game 可優化 TODO 清單

## 🎯 優化分類

### 🔴 High Priority (核心體驗)

#### 1. 遊戲邊框顯示問題
**問題**: Graphics 繪製的白色邊框在預覽中看不到  
**原因**: 可能是 Graphics 組件渲染順序或 z-index 問題  
**解決方案**:
- [ ] 創建獨立 Border 節點，設定正確的渲染層級
- [ ] 使用 Node.setPosition 調整 z 軸位置
- [ ] 或改用 Label + 背景色模擬邊框效果
- [ ] 測試不同 lineWidth (5px → 10px)

**預估時間**: 30 min  
**難度**: Medium

---

#### 2. 遊戲重新開始功能
**問題**: 死亡後無法重新開始遊戲  
**原因**: StartButton 沒有配置 ClickEvent  
**解決方案**:
- [ ] 給 StartButton 添加 Button 組件的 clickEvents
- [ ] 呼叫 SnakeGame.startGame()
- [ ] 或監聽 Button 的 click 事件
- [ ] 死亡後顯示按鈕，點擊後重置遊戲

**預估時間**: 20 min  
**難度**: Easy

---

#### 3. 食物生成位置可視化
**問題**: 食物可能在蛇身上生成（等待 100 次嘗試）  
**原因**: 只檢查蛇身位置，沒有視覺提示  
**解決方案**:
- [ ] 添加食物生成動畫效果（閃爍）
- [ ] 限制最大嘗試次數後，強制生成在空位
- [ ] 或預先計算所有空位，隨機選擇

**預估時間**: 15 min  
**難度**: Easy

---

### 🟡 Medium Priority (體驗提升)

#### 4. 蛇身移動動畫
**問題**: 蛇移動是「瞬間跳躍」，缺乏流暢感  
**原因**: 每次移動直接 setPosition  
**解決方案**:
- [ ] 添加 Tween 緩動效果（移動 0.15 秒）
- [ ] 蛇身跟隨頭部平滑移動
- [ ] 蛇身增長時添加淡入效果
- [ ] 設計「蛇身彎曲」的曲線移動

**預估時間**: 45 min  
**難度**: Medium

---

#### 5. 分數與遊戲狀態 UI
**問題**: UI 只有文字，缺乏遊戲氛圍  
**原因**: Label 組件最簡單，沒有設計  
**解決方案**:
- [ ] 添加遊戲標題（Title Label）
- [ ] 分數增加時添加動畫（放大 → 恢復）
- [ ] 死亡時顯示「Game Over」大字
- [ ] 添加最高分數記錄（localStorage）

**預估時間**: 30 min  
**難度**: Easy

---

#### 6. 鍵盤提示與說明
**問題**: 沒有操作說明，玩家不知道如何控制  
**原因**: 開發者知道，但新玩家不知道  
**解決方案**:
- [ ] 添加控制說明 UI（↑↓←→ 或 WASD）
- [ ] 在遊戲區域下方顯示提示文字
- [ ] 遊戲開始前顯示「Press Arrow Keys to Start」
- [ ] 添加暫停功能（P 鍵）

**預估時間**: 20 min  
**難度**: Easy

---

### 🟢 Low Priority (進階功能)

#### 7. 遊戲速度調整
**問題**: 移動速度固定（0.2 秒），無難度變化  
**原因**: moveInterval 是常數  
**解決方案**:
- [ ] 分數增加時加快速度（每 50 分加快 0.05 秒）
- [ ] 添加速度選項（慢/中/快）
- [ ] 顯示當前速度等級
- [ ] 設定速度上限（最快 0.05 秒）

**預估時間**: 25 min  
**難度**: Easy

---

#### 8. 音效系統
**問題**: 靜音遊戲，缺乏沉浸感  
**原因**: 沒有 Audio 組件  
**解決方案**:
- [ ] 添加背景音樂（循環播放）
- [ ] 吃食物音效（短促音效）
- [ ] 死亡音效（碰撞聲）
- [ ] 移動音效（可選）

**預估時間**: 60 min  
**難度**: Medium（需準備音效資源）

---

#### 9. 關卡/障礙物系統
**問題**: 只有牆壁碰撞，遊戲太簡單  
**原因**: MVP 版本只實現核心邏輯  
**解決方案**:
- [ ] 添加障礙物（靜態方塊）
- [ ] 不同關卡有不同障礙物配置
- [ ] 隨機生成障礙物
- [ ] 障礙物碰撞檢測

**預估時間**: 90 min  
**難度**: Hard

---

#### 10. 多人/對戰模式
**問題**: 單人遊戲，缺乏競爭性  
**原因**: MVP 版本，沒有網路功能  
**解決方案**:
- [ ] 本地雙人模式（兩條蛇，不同控制鍵）
- [ ] WebSocket 網路對戰
- [ ] 排行榜系統
- [ ] 房間/匹配系統

**預估時間**: 180+ min  
**難度**: Hard（需要後端支援）

---

### 🔵 Code Quality (代碼優化)

#### 11. 組件分離
**問題**: SnakeGame.ts 包含所有邏輯（400+ 行）  
**原因**: MVP 快速開發，沒有架構設計  
**解決方案**:
- [x] **跳過** - 當前功能完整，組件分離風險較高
- 方法良好組織，代碼清晰度已足夠
- 未來維護時可考慮分離（如有需要）

**預估時間**: 60 min  
**難度**: Medium  
**狀態**: ✅ SKIPPED (保持當前代碼)

---

#### 12. 單元測試
**問題**: 沒有測試，修改後可能出 bug  
**原因**: MVP 版本，沒時間寫測試  
**解決方案**:
- [ ] 添加 Jest 或 Vitest
- [ ] 測試碰撞檢測邏輯
- [ ] 測試食物生成邏輯
- [ ] 測試座標轉換函數

**預估時間**: 90 min  
**難度**: Medium

---

#### 13. 状态管理
**問題**: 用 isPlaying boolean 管理狀態，不夠靈活  
**原因**: MVP 版本，簡單實現  
**解決方案**:
- [ ] 使用 Enum 管理狀態（IDLE, PLAYING, PAUSED, GAME_OVER）
- [ ] 或用狀態機模式
- [ ] 每個狀態有對應的 UI 和邏輯

**預估時間**: 30 min  
**難度**: Easy
